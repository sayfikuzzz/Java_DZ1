# Практическая работа № 1

Вариант 30 для задания 1, вариант 10 для заданий 2 и 3.

## Что где лежит

| Файл | Задание |
|------|---------|
| `src/Task1.java` | Задание 1, вариант 30 — исправление объявлений переменных |
| `src/Task2.java` | Задание 2, вариант 10 — вычисление функции `y = x * sqrt(x) + x^5 + exp(x)` |
| `src/Task3.java` | Задание 3, вариант 10 — сумма двух наибольших из трёх чисел |

В каждом файле есть подробные комментарии к каждой строке: что она делает и почему написана именно так.

## Как запустить

### В IntelliJ IDEA

1. Открыть проект `Djava_DZ1`.
2. Открыть нужный файл, например `src/Task1.java`.
3. Нажать зелёный треугольник рядом с методом `main` и выбрать `Run 'Task1.main()'`.

Для `Task2` и `Task3` программа попросит ввести числа в консоли — ввести значение и нажать `Enter`. Дробную часть можно писать и через запятую, и через точку: `2,5` или `2.5`.

### Через командную строку

Из папки проекта:

```bash
javac -encoding UTF-8 -d out src/Task1.java src/Task2.java src/Task3.java
java -cp out Task1
java -cp out Task2
java -cp out Task3
```

## Кратко о решениях

### Задание 1 (вариант 30)

Исправлены ошибки в объявлениях:

- `String` требует кавычек, а в конце строки нужна `;`;
- `integer` и `number` — не типы Java (есть `int`, `double`, `Integer`);
- `'x'` — это `char`, а не `int`/`boolean`;
- `boolean` хранит только `true`/`false`;
- `case` и `int` — ключевые слова, их нельзя использовать как имена переменных;
- имена переменных не должны повторяться (`value`, `java`);
- дробный литерал по умолчанию имеет тип `double`, для `float` нужен суффикс `f`.

### Задание 2 (вариант 10)

Формула:

```
y = x * √x + x⁵ + eˣ
```

В Java:

```java
double y = x * Math.sqrt(x) + Math.pow(x, 5) + Math.exp(x);
```

Значение `x` вводится с клавиатуры через `Scanner`. Корень `√x` определён при `x >= 0`.

### Задание 3 (вариант 10)

Сумма двух наибольших чисел из трёх равна сумме всех трёх минус наименьшее:

```java
double min = a;
if (b < min) min = b;
if (c < min) min = c;
double sum = a + b + c - min;
```

Здесь используется условный оператор `if`, как требуется в задании.
